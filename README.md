# Contact Management System

A beginner-friendly Python command-line application for managing contacts using CRUD operations, dictionaries, JSON file storage, regular expressions, exception handling, and modular programming.

## Project Overview

The Contact Management System allows users to create, view, search, update, and delete contact information.

The project demonstrates important Python programming concepts such as:

- Dictionaries
- Lists
- Functions
- JSON
- File Handling
- Regular Expressions
- Exception Handling
- CRUD Operations
- Input Validation
- Modular Programming

## Features

- Display all contacts
- Search contacts by name, phone, or email
- Add new contacts
- Update existing contacts
- Delete contacts
- Validate phone numbers using Regex
- Validate email addresses using Regex
- Prevent duplicate phone numbers
- Prevent duplicate email addresses
- Store contact data in JSON
- Handle invalid input and errors
